# Retired finding labels: where they live now

Open architectural findings are [GitHub issues labelled `finding`](https://github.com/jcogilvie/unjira/issues?q=label%3Afinding).
The `F<n>` labels below were file names under `docs/findings/`, retired when the findings moved
(#150). The label is kept in each issue's title, so old references in commits, journals and specs
resolve either way. New findings get no `F<n>`; they are cited as `#N`.
